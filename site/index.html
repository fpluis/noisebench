Overview Noise Yes/No bias Details

Ask a language model the same forecasting question twice and you get two different answers. Ask it the same question phrased backwards and the two answers may not even add up. This benchmark measures that — how much a model agrees with itself, never whether it was right. Twenty models, 100 Polymarket questions, 24,000 forecasts.

Consistency

One score per model, averaging five checks that a coherent forecaster would pass automatically. Higher is better. A model answering at random would score —, marked on the chart — so the distance above that line, not the raw height, is what a model has earned.

What goes into the score

Five checks, equally weighted. Two ask whether a model repeats itself; three ask whether its answers are logically compatible with each other. Each is a plain percentage with its own coin-flip baseline, shown beside it.

Where each model gains and loses

The same five checks, per model. Repeating yourself turns out to be much easier than staying logically coherent — the two repeat scores run high across the field while the negation checks collapse.

Does a model's pick match the odds it just gave?

Asked "which of these two is likelier?", a model should pick whichever it had already given the higher probability. Here every such comparison is grouped by how far apart the model's own two probabilities were. Where that gap is near zero, the model is genuinely torn and either pick is defensible — 50% is correct behaviour, not a failure. The question is how fast the line climbs once the model has staked out a real difference.

Pooled across all twenty models, because a single model contributes only about 200 of these comparisons and the buckets get too thin to read. Restricted to the "which is likelier" comparisons: the other two wordings ask whether the pair's probabilities sum past 100%, which on a set of questions this skewed toward long shots is usually an easy call and would flatter the right-hand end.
